# روايات المصحف — تطبيق «سبعون مرة»

ملفات الخلاف بين رواية حفص عن عاصم وسبع روايات أخرى، كلمة كلمة، يحمّلها تطبيق
«سبعون مرة» عند الطلب ليعرض المصحف برواية القارئ: الصفحة نفسها بخط حفص وسطوره،
والكلمة المختلفة مكتوبة كما تُقرأ وملوّنة بنوع الخلاف.

| الملف | الرواية |
|---|---|
| `warsh.tsv.gz` | ورش عن نافع |
| `qaloon.tsv.gz` | قالون عن نافع |
| `shouba.tsv.gz` | شعبة عن عاصم |
| `bazzi.tsv.gz` | البزي عن ابن كثير |
| `qumbul.tsv.gz` | قنبل عن ابن كثير |
| `doori.tsv.gz` | الدوري عن أبي عمرو |
| `soosi.tsv.gz` | السوسي عن أبي عمرو |

`index.json` فيه حجم كل ملف وبصمته (SHA-256) ورقم النسخة.

## المصدر

نصوص الروايات الثماني من **مجمع الملك فهد لطباعة المصحف الشريف**. الخلاف مستخرج
آليًا بمقارنة نص كل رواية بنص حفص، **ويحتاج إلى مراجعة متخصص مُجاز في القراءات**
قبل الاعتماد عليه.

## شكل الملف

نص UTF-8 مضغوط بـgzip، كل سطر حقول مفصولة بـTab:

```
# qiraat <النسخة> <المعرّف> <عدد الكلمات>
C <أسماء الأنواع بترتيب البتات>
W <السورة> <آية حفص> <ترتيب الكلمة في الآية> <الصفحة> <بتات الأنواع> <الكلمة كما تُقرأ بضبط حفص>
E <السورة> <آية حفص> <رقم الآية في الرواية، أو 0 إذا لم تكن رأس آية فيها>
X <السورة> <آية حفص> <ترتيب الكلمة> <رقم الآية في الرواية بعد هذه الكلمة>
```

ترتيب الكلمة يبدأ من الصفر ولا يعدّ «۞» ولا «۩». سطر `E` يأتي فقط حين يختلف رقم
الآية عن حفص.

## النسخ

كل نسخة لها وسم ثابت (`v1`، `v2`...) ولا تتغير ملفاتها بعد نشرها. التطبيق يقرأ
`index.json` من أحدث وسم، ثم يحمّل الملفات من الوسم المكتوب فيه.
